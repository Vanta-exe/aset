# Built-in Crimson profiles

These are configuration data files for builds containing the Mouse Input 0.8
aim mode (NativeAim mode 3). They contain no executable code or credentials.

| Profile | Selected mode | FOV | Mouse speed | ESP |
|---|---|---|---|---|
| legit | Mouse Input | 4 degrees | 1x | boxes, health, names, distance |
| semi legit | Mouse Input | 7 degrees | 1.5x | enabled |
| rage | Standard | 55 degrees | not used by Standard | enabled |
| very rage | Silent | 180 degrees | not used by Silent | enabled |

Mouse Input profiles use right mouse by default; keyless is initially off.
The standard/silent aim binding is Mouse4; the separate trigger binding is
Mouse5. Mouse sensitivity is 2.0 and should match the game setting.

The `confing/` copies are retained for clients using the older folder spelling.
The preset index pins data downloads to a Git commit and records exact byte
lengths and SHA-256 values. Only compatible updated clients use this preset
index. The separate signed artwork/inventory manifest remains unchanged.
