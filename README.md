# Crimson static assets

Runtime images, inventory catalogs, radar, themes, chams materials and the current six native-enhanced skyboxes.

Download ZIP parts from the Release. Folder structure is preserved. The signed manifest and pinned public key are consumed by the standalone asset client; SHA-256 is checked for packages and extracted files. Existing valid files are reused.

Only static assets are published. No loader, DLL, executable, license database, private key or credentials are included.
