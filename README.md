# Crimson static assets

Current release: `assets-20261018-v2`.

2,185 individual static files. No ZIP download or manual extraction.
Inventory contains 2,116 skin preview images plus the catalog. Six native-enhanced
sky themes are included with their compiled materials and textures.

Files below 90 MiB live in `assets/` in this repository. The six large sky textures
are individual Release attachments. The signed manifest records each file's exact
path, URL, byte length and SHA-256. The application automatically downloads missing
or damaged files, verifies them and selects the completed installation.

No executable, loader, DLL, driver, private key, credential or license database is
part of this asset repository. Older ZIP releases are retained for old clients.
